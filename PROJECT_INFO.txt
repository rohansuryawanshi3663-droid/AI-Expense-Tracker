AI Expense Tracker - Project Info

Purpose:
Build a simple, mobile-friendly personal expense tracker with useful spending analytics.

Main files:
- app.py: Streamlit user interface, pages, charts, forms and downloads
- database.py: SQLite persistence and CRUD functions
- ai_engine.py: category suggestion and explainable spending insights
- requirements.txt: Python dependencies
- README.md: setup and deployment guide

Features:
1. Add, edit and delete expenses
2. Interactive dashboard and charts
3. Category suggestions based on transaction descriptions
4. Monthly budget tracking and alerts
5. Spending insights and a simple next-month estimate
6. Downloadable CSV reports

Limitations:
The app uses local SQLite storage. Hosted app local storage may reset. Insights are rule-based, not generated by a large language model.
