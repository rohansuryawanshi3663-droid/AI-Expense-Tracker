# 💰 AI Expense Tracker

A beginner-friendly **Python + Streamlit** project for recording expenses and visualising spending habits.

## Features

- Add daily expenses
- Categorise expenses
- Calculate total, average and highest spending
- Spending-by-category chart
- Daily spending chart
- Expense history table
- Download expenses as CSV
- Basic automated spending insights

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- CSV data storage

## How to Run

1. Install Python.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Start the dashboard:

```bash
streamlit run app.py
```

4. Open the local Streamlit link shown in the terminal.
